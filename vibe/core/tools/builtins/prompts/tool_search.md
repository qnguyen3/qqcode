# Tool search

Some tools are not part of the default tool list to keep the request small
(deferred exposure). When you need a capability you cannot see, call
`tool_search` with a few keywords describing what you want to do.

- Matching tools are listed with their names and descriptions.
- Matched tools are exposed for the rest of the current turn, so you can call
  them right away.
- If nothing matches, try different keywords or a broader term.

Only search when the tool you need is missing; the tools already in your list
are always the fastest path.
